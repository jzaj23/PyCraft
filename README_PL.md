# PyCraft Website

Profesjonalna, responsywna strona promocyjna PyCraft Launcher. Zwykły HTML, CSS i JavaScript — bez frameworków i instalowania zależności.

## Podgląd lokalny
Otwórz `index.html` w przeglądarce.

## Publikacja przez GitHub Pages
1. Wejdź do repozytorium `jzaj23/PyCraft`.
2. Dodaj `index.html`, `style.css`, `script.js` i folder `assets` do głównego katalogu repozytorium.
3. Zapisz zmiany przez **Commit changes**.
4. Otwórz **Settings → Pages**.
5. W sekcji **Build and deployment** wybierz **Deploy from a branch**.
6. Wybierz gałąź `main` oraz folder `/ (root)` i kliknij **Save**.
7. Po chwili GitHub pokaże adres opublikowanej strony w sekcji Pages.

Możesz też utworzyć osobne repozytorium `PyCraft-Website` i umieścić w nim te pliki.

## Edycja
- `index.html` — teksty, sekcje i linki.
- `style.css` — wygląd, kolory i responsywność.
- `script.js` — animacje pojawiania się sekcji i menu mobilne.
- `assets/logo.svg` — logo.

Strona nie udaje, że EXE jest już dostępne. Linki prowadzą do aktualnego repozytorium źródłowego.
