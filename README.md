# PyCraft Launcher

**Your World. Your Rules.**

PyCraft Launcher is an independent Minecraft Java launcher project created by Jakub.

The goal of PyCraft is to provide a convenient way to manage Minecraft installations, game versions, mods and modpacks through a custom graphical interface.

The project is developed in Python and focuses on simplicity, customization and expanding Minecraft modding possibilities.

Main goals
- Easy Minecraft instance management
- Modrinth integration
- CurseForge integration
- Mod and modpack management
- Custom graphical interface
- Minecraft server management
- Continuous development and new features

Developer: Jakub  
Language: Python  
Platform: Windows  
Project: Independent / Open Source
